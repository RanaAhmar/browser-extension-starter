# 🚀 Browser Extension Starter

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Vite](https://img.shields.io/badge/Vite-646CFF?style=flat&logo=vite&logoColor=white)](https://vitejs.dev/)
[![React](https://img.shields.io/badge/React-20232A?style=flat&logo=react&logoColor=61DAFB)](https://reactjs.org/)

A modern, high-performance boilerplate for building cross-browser extensions using **Vite**, **React**, and **Tailwind CSS**. Optimized for developer experience and lightning-fast builds.

---

## 🌟 Features

- **Vite-Powered:** Instant Hot Module Replacement (HMR) even inside the extension context.
- **Modern Stack:** React 18+ for UI, Tailwind CSS for rapid styling.
- **TypeScript Ready:** Full type safety out of the box.
- **Manifest V3:** Fully compliant with the latest Chrome/Edge extension standards.
- **Shadow DOM Support:** Keep extension styles isolated from host pages.
- **Background/Popup/Content Scripts:** Pre-configured and ready to use.

---

## 🛠️ Quick Start

1. Clone the repo:
   ```bash
   git clone https://github.com/AhmarHussain/browser-extension-starter.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run in development mode:
   ```bash
   npm run dev
   ```
4. Load the `dist/` folder in your browser (Developer Mode > Load Unpacked).

---

## 📖 Why this starter?

Most extension boilerplates are either outdated or too complex. This starter focuses on simplicity and speed, allowing you to go from idea to prototype in minutes.
